# Reclaimed downloads

Official beta installers for [Reclaimed](https://reclaimed.email/).

- [Download the Windows x64 beta](https://github.com/zemdei/Reclaimed-Downloads/releases/latest/download/Reclaimed-Setup-win-x64.exe)
- [Release notes, SHA-256 checksums and build manifest](https://github.com/zemdei/Reclaimed-Downloads/releases/latest)
- [Free email signature builder](https://signature.reclaimed.email/)

Requires Windows 10 build 19041 or later, or Windows 11, on x64. The installer
includes the self-contained .NET app and the Microsoft WebView2 prerequisite.
This beta is not code-signed. App source code is maintained separately and is
not included in this repository. Provider approval and account onboarding can
have separate availability limits during beta.

The signature builder's **Add to your Reclaimed inbox** action requires the
current installer. The app lets you choose an account, review the signature and
save separate defaults for new messages and replies. Signature contents transfer
through your device clipboard, without being uploaded by the handoff.
